WordPress lent ?

Optimiser ou refaire : lisez vos cadrans avant de décider.

Un WordPress lent n'est pas une fatalité. Ses causes sont généralement identifiables, et le choix entre optimisation et refonte dépend de ce qui ralentit réellement le site. Saisissez vos trois Core Web Vitals, puis répondez à huit questions : vous repartez avec un verdict et un plan d'action.

Comment les couleurs sont-elles attribuées ?

Vert : la valeur respecte le seuil de l'article (LCP 2,5 s ou moins, INP 200 ms ou moins, CLS 0,1 ou moins).

Orange puis rouge : l'article ne donne que le seuil du « bon » résultat. Pour séparer l'orange du rouge, l'outil applique une convention : jusqu'au double du seuil, la valeur est orange ; au-delà, elle est rouge (soit 5 s pour le LCP, 400 ms pour l'INP, 0,2 pour le CLS).
