## Mon site WordPress est lent : l'optimiser ou le refaire ? (article de blog)
- Idée centrale : un WordPress lent n'est pas une fatalité ; ses causes sont généralement identifiables et le choix entre optimisation et refonte dépend de ce qui ralentit réellement le site.
- Core Web Vitals (indicateurs Google) : LCP (chargement) 2,5 s ou moins ; INP (réactivité) 200 ms ou moins ; CLS (stabilité visuelle) 0,1 ou moins. Sur WordPress, c'est surtout le LCP qui pose problème.
- Causes principales : thème et constructeur de pages lourds ; extensions nombreuses ; images non optimisées ; hébergement d'entrée de gamme ; scripts tiers.
- Diagnostic : PageSpeed Insights en version mobile ; poids de la page ; audit des extensions ; temps de réponse du serveur ; images les plus lourdes.
- Optimisations possibles sans refonte : compression et format moderne des images ; cache bien configuré ; nettoyage des extensions ; gestion des scripts tiers ; polices locales ; hébergement adapté ; CDN.
- Quand refaire : constructeur de pages lourd qui reste lent après optimisation ; site vitrine peu modifié ; accumulation d'extensions ; piratage passé ; design daté.
- Référencement pendant une refonte : conserver les adresses ou mettre en place des redirections 301 ; reprendre les contenus utiles ; soumettre le nouveau plan de site à Search Console.
